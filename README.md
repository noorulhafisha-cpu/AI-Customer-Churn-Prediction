AI Customer Churn Prediction

Project Overview

This project uses machine learning to predict whether a telecom customer is likely to leave a service. It also provides retention recommendations based on the predicted churn risk.

Features

- Predicts customer churn using a Random Forest model
- Displays churn probability
- Identifies customer risk levels
- Provides customer retention recommendations
- Interactive web application using Streamlit

Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Jupyter Notebook

How to Run

Install the required libraries and run the application using:

python -m streamlit run app.py

The trained model file and feature list must also be present in the project folder.

Dataset

Telco Customer Churn dataset, used for educational and portfolio purposes.
